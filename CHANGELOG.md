# Changelog

## 0.1.0 — 2026-09-17

First public alpha.

- `reacli==0.1.0`: CLI and Python library (`rac`) for RPP inspection, Lua generation, isolated REAPER execution, and project/audio checks.
- `reaper-parser==0.1.0a1`: standalone lossless RPP parser used by `reacli`.
- Offline parser support on macOS, Linux and Windows. REAPER execution on macOS and Linux only.
